# شعارات الأندية

ضع شعار كل نادٍ هنا بصيغة PNG (يفضّل خلفية شفافة ومربع تقريباً) باسم معرّف النادي:

raja.png, wydad.png, far.png, berkane.png, mas.png, fus.png, husa.png, safi.png, tanger.png, dhj.png

وللأندية الأخرى: mancity.png, real.png, barca.png, psg.png ... (المعرّفات في `src/career/clubs.ts`).

الشعار الناقص يظهر كدرع مرسوم بألوان النادي (ألوان تقريبية قابلة للتعديل في `BRAND`) ولا يتعطل التطبيق.
تأكد من حقوق استخدام الشعارات قبل نشر الفيديوهات.
